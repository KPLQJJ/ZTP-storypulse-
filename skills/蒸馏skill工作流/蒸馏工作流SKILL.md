# 蒸馏Skill工作流

将某一文学主题（悬疑、修仙、都市、科幻、历史、女频等）的多部头部作品，系统性地蒸馏为一套该分类通用的创作+润色+审稿 Skill。

## 工作流总览

```
阶段一：单本提炼（逐本执行）
  作品A → [创作提炼] [润色提炼] [审稿提炼] → 3个单本Skill
  作品B → [创作提炼] [润色提炼] [审稿提炼] → 3个单本Skill
  作品C → [创作提炼] [润色提炼] [审稿提炼] → 3个单本Skill

阶段二：综合凝练（收集≥2套后执行）
  单本A Skill ┐
  单本B Skill ├→ 横向对比 → 去重合并 → 层级升级 → 3个分类通用Skill
  单本C Skill ┘
```

---

## 阶段一：单本提炼

### 输入要求

- 一部完整作品的小说文本（TXT/MD格式）
- 该作品所属的文学分类（如悬疑、修仙等）
- 对作品的基本认知（主线剧情、核心设定、主角特征）

### 提炼方法

分三轮对话，每轮以不同角色定位阅读和分析作品全文，产出对应的 Skill 文件。三轮应独立执行，不应在前一轮的 Skill 中混入后一轮的关注点。

---

### 1.1 创作 Skill 提炼

**角色定位：该分类的资深作者**

你是一位在该分类深耕多年的顶尖作家，你的作品被同行视为该分类的写作教科书。你的关注点是：

- 这本书的**写作技法**好在哪？作者用了什么具体手法？
- 如果你是作者，你会如何向其他写作者**传授**这些技法？
- 哪些手法是**可迁移、可复用**的？不是"这本小说有个好点子"，而是"这个好点子背后的写作原理是什么"。

**提炼维度（按此顺序组织输出）：**

1. **开篇设计** — 首章如何锚定读者？异常事件如何引入？主角如何被卷入核心冲突？信息锚点如何设置？
2. **悬念布局与回收** — 悬念体系的层级结构（微型/小型/中型/大型/巨型）？回收节奏？反转类型与频率？伏笔密度与呼应机制？
3. **规则与设定交代** — 世界观规则如何渐进式揭示？角色如何通过试错学习规则？信息如何分层交付？道具与对话如何承载设定？
4. **章末钩子与断点** — 钩子类型分布？断点位置选择逻辑？多线切换策略？安全-危险交替结构？
5. **角色与核心驱动结合** — 角色立场灰度设计？信息不对称如何驱动人物关系？能力如何成为解谜工具？阵营如何动态调整？
6. **冲突与高潮设计** — 战力体系如何建立参照？胜负如何多因素决定？损耗如何持续？冲突如何升级？
7. **节奏与氛围** — 张弛交替比例？多线节奏如何协调？氛围如何通过感官细节建立？恐惧/紧张如何渐进升级？

**输出格式要求：**

- 每个维度下以**指令式语言**撰写（"应……"、"不应……"、"采用……而非……"）
- 每条指令必须源于该作品中的**具体段落或情节**，不应写泛泛而谈的通用建议
- 关键技法需附**作品中的实例**（一句话概括即可，如"如第X章中……"）
- 末尾附 **核心原则**（2-3条一句话级创作纲领）

---

### 1.2 润色 Skill 提炼

**角色定位：该分类的资深编辑**

你是一位在该分类从业十年以上的资深文学编辑，经手过上百本该分类的头部作品。你拿到一份稿件后，能在30分钟内精准定位所有影响读者体验的问题。你的关注点是：

- 这本书**如果交给一个水平尚可但经验不足的作者**，最可能在哪类描写上失控？
- 哪些段落的处理方式体现了**克制**——作者用少的信息传递了多的含义？
- 哪些地方如果换一种写法，效果会差多少？怎么改？

**提炼维度（按此顺序组织输出）：**

1. **描写有效性判断** — 什么描写是该分类必须保留的（功能检验）？什么描写是冗余的（冗余信号）？环境/动作/心理描写的各类检验标准是什么？
2. **对话张力** — 该分类的有效对话应具备什么特征？潜台词如何构建？信息交换率如何衡量？应改写和应避免的对话模式有哪些？
3. **节奏量化** — 快/中/慢节奏段落的特征和切换规则？信息释放密度控制？章节紧张值曲线管理？段间调节技巧？
4. **修改优先级体系** — P0（必须修改）到 P3（酌情优化）的分级标准和具体检查项？修改应从哪个层级开始（章节 > 段落 > 句子）？

**输出格式要求：**

- 以**检验标准**为核心组织（"满足X条件的描写应保留，满足Y条件的应删除"）
- 每条标准应可通过**人工或AI辅助检查**来验证（可操作、可判断）
- 优先级体系必须有明确的**判断阈值**（如"连续X页快节奏需插入缓冲"）
- 末尾附 **润色核心原则**（1-2条）

---

### 1.3 审稿 Skill 提炼

**角色定位：该分类的资深审稿人**

你是一位专攻该分类的文学评论家和审稿人，你的审稿意见被多家平台作为签约决策依据。你审稿时不看"作者想表达什么"，只看"读者实际接收到了什么"。你的关注点是：

- 这份稿件的**长板和短板**分别在哪里？
- 如果只能提 3 条修改建议，你会提什么？为什么是这 3 条？
- 这本稿件的**上限**在哪里——如果所有问题都修了，它能达到什么水准？

**提炼维度（按此顺序组织输出）：**

1. **设定创新性** — 核心设定的辨识度、世界观自洽程度、设定与分类驱动力的绑定深度
2. **悬念设计** — 悬念层次是否分明、回收节奏是否合理、答案的可预测性与意外性平衡
3. **节奏把控** — 张弛交替是否有效、信息释放密度是否恰当、断点位置是否精准
4. **人物塑造** — 角色是否功能化/标签化、动机是否可追溯、是否有情感锚点、配角是否有辨识度
5. **氛围渲染** — 氛围是否与情节绑定、感官细节是否精准、不同场景氛围是否有差异化
6. **逻辑自洽** — 规则是否前后一致、能力边界是否清晰、角色行为是否可回溯理解
7. **开篇吸引力** — 首章是否有异常/冲突/悬念、读者能否在合理篇幅内建立阅读动机

**每个维度的输出结构（固定格式）：**

```
**低分（1-3）**：<该维度不合格的具体表现>
**中分（4-7）**：<该维度合格但有不足的具体表现>
**高分（8-10）**：<该维度出色的具体表现>

审稿检查：
- <可操作的检查问题1>
- <可操作的检查问题2>
- <可操作的检查问题3>
```

**输出格式要求：**

- 开头声明评分总则（总分、分档含义）
- 每个维度必须同时包含**低分/中分/高分三档的具体描述**和**审稿检查项**
- 低分描述应能映射到该作品的**具体不足之处**（如有）；高分描述应能映射到该作品的**具体出色之处**
- 末尾附 **快速对照卡**（一段话总结各维度的一票否决条件）
- 末尾附 **S/A/B/C/D 评级区间**（对应总分范围）

---

### 阶段一输出物

每部作品产出 3 个文件，存放在：

```
xiangm_tudou/skills/{分类}/{作品名}/
├── 创作_Skill.md
├── 润色_Skill.md
└── 七维审稿_Skill.md
```

## 阶段二：综合凝练

### 触发条件

同一分类下已积累 ≥2 套完整的单本 Skill（即 ≥6 个文件：2×创作 + 2×润色 + 2×审稿）。建议 3-5 套为最佳凝练基数。

### 输入

- 同一分类下所有单本 Skill 文件（创作/润色/审稿分开处理）
- 各作品的简要特征说明（代表作风格、独特贡献）

### 综合方法论

按 Skill 类型分别执行以下流程（创作、润色、审稿各自独立综合）：

#### 第1步：横向对比

将同类型的所有单本 Skill（如 3 本作品的创作 Skill）并排对比，逐章节标记：

- **共有模式**（≥2 本都出现的技法/原则）→ 标记为"候选通用原则"
- **独有技法**（仅 1 本出现的独特手法）→ 标记为"特殊案例"，保留但降级
- **矛盾观点**（不同单本对同一问题的建议相反）→ 标记为"需研判"，分析矛盾原因

#### 第2步：去重合并

- 同一概念在不同单本 Skill 中以不同措辞出现 → 合并，取表述最精确的版本
- 同一维度下的多条原则存在包含关系（A 是 B 的特例）→ B 保留为主原则，A 降为子项
- 仅 1 本支撑的"原则" → 降级为"参考技法"或删除（除非该技法具有极高的分类代表性）

#### 第3步：层级升级

将单本 Skill 中"该作品使用了 X"的语言升级为分类通用语言：

- "该作品以 Y 方式处理 X" → "该分类应采用 Y 原则处理 X"
- "主角在面对 Z 时选择了 W" → "该分类主角在面对 Z 时，通常有 W1/W2/W3 三种有效处理方式"
- 实例从"如第X章"改为概括性的"如典型情况下的……"（去具体化，保留本质）

#### 第4步：结构重组

按分类通用 Skill 的标准章节目录重组内容：

- **创作 Skill**：开篇设计 → 悬念布局与回收 → 规则与设定交代 → 章末钩子与断点 → 角色与核心驱动结合 → 冲突与高潮设计 → 节奏与氛围 → 核心原则
- **润色 Skill**：描写有效性判断 → 对话张力 → 节奏量化 → 修改优先级体系 → 核心原则
- **审稿 Skill**：设定创新性 → 悬念设计 → 节奏把控 → 人物塑造 → 氛围渲染 → 逻辑自洽 → 开篇吸引力 → 快速对照卡 → 评级区间

#### 第5步：审查验证

对每条纳入综合版的原则执行以下检查：

- **多源支撑**：是否至少有 2 本作品的单本 Skill 支撑该原则？低于 2 本 → 降级或删除
- **可操作性**：该原则是否可以被不熟悉该分类的作者理解和执行？不可操作 → 重写
- **分类特异性**：该原则是否在该分类中特别重要或特别有效？如果放之四海皆准 → 判断是否属于通用提示词范畴而非分类专用
- **无矛盾**：同一 Skill 文件内不同章节的原则是否存在互斥？有矛盾 → 辨析后选择适用场景更明确的一方

---

### 阶段二输出物

每个分类产出 3 个文件，存放在：

```
xiangm_tudou/skills/{分类}/综合版/
├── 创作_Skill.md
├── 润色_Skill.md
└── 七维审稿_Skill.md
```

## 质量验收标准

### 单本 Skill 验收

- [ ] 每个 Skill 文件覆盖其全部提炼维度（创作 7 维 / 润色 4 维 / 审稿 7 维）
- [ ] 每条指令/标准来源于该作品的具体内容（有实例支撑）
- [ ] 三种 Skill 之间的角色视角有明显区分（创作技法 ≠ 润色标准 ≠ 审稿维度）
- [ ] 指令式语言（"应……"、"不应……"），不含模棱两可的"可以"、"建议"
- [ ] 审稿 Skill 的每个维度有低分/中分/高分三档描述和审稿检查项

### 综合版 Skill 验收

- [ ] 每条通用原则至少有 2 本单本 Skill 支撑
- [ ] 不存在直接复制粘贴单本 Skill 内容的情况（已做层级升级）
- [ ] 结构完整，章节顺序符合标准目录
- [ ] 独有技法已标注为"特殊案例"或"变体"
- [ ] 无内部矛盾（同一 Skill 内不同章节的原则一致）
- [ ] 审稿 Skill 末尾有快速对照卡和评级区间

---

## 使用方式

### 新建分类 Skill

```
阶段一：对分类下的每部作品，依次执行阶段一的三个提炼流程
  → 每部作品产出 3 个单本 Skill
阶段二：收集 ≥2 套单本 Skill 后，执行阶段二的综合凝练
  → 产出分类通用 Skill（3 个文件）
```

### 复用已有单本 Skill

如果某个分类已有单本 Skill（如悬疑类的十日终焉、诡舍、异兽迷城），可直接进入阶段二，以已有单本 Skill 作为输入执行综合凝练。

### 补充新作品到已有分类

```
1. 对新作品执行阶段一 → 产出 3 个新单本 Skill
2. 以已有综合版 + 新单本 Skill 为输入，重新执行阶段二
3. 新作品可能带来新的独特技法 → 更新综合版
```
