# 悬疑类·七维审稿 Skill

## 一、设定创新性（0-10分）

**低分表现（0-3分）：** 设定完全可预测，核心概念在其他作品中反复出现；世界观缺乏内在逻辑；能力体系无新意。

**中分表现（4-7分）：** 核心概念有一定新意，但部分元素有借鉴痕迹；世界观有基本逻辑但存在未解释的盲区；能力体系有特色但不突出。

**高分表现（8-10分）：** 核心设定具有高度辨识度；世界观逻辑自洽且存在多层级递进；能力/规则体系有原创性机制，且能与悬疑驱动深度绑定。

审稿检查项：
- 该设定的核心创意是否能在三句话内说清且让人产生兴趣？
- 设定是否存在"只有作者知道"的隐藏规则，还是读者可通过已有信息推导？
- 设定是否与悬疑驱动直接挂钩（而非仅为战斗服务）？

## 二、悬念设计（0-10分）

**低分表现（0-3分）：** 悬念缺乏层次，多为"是否存活"式即时悬念；无长期悬念锚点；回收节奏紊乱或长期悬置。

**中分表现（4-7分）：** 存在多层级悬念，但部分回收过早或过晚；悬念与悬念之间关联较弱；读者能大致预测部分答案。

**高分表现（8-10分）：** 即时、章节、核心三级悬念并存且联动；每次回收都产生新的衍生悬念；答案在"可预测但需推理"与"意外但可回溯"之间的最佳区间。

审稿检查项：
- 读完1万字后，读者心中是否有明确的"我想知道的事"？
- 最近一次悬念回收是否产生了新的疑问？
- 是否存在悬置时间超过读者耐心的悬念？

## 三、节奏把控（0-10分）

**低分表现（0-3分）：** 战斗与日常比例失调；信息释放过密或过疏；章节断点位置随意；读者易产生阅读疲劳。

**中分表现（4-7分）：** 有基本的张弛意识，但部分段落拖沓或压缩过度；断点有效性不稳定；高强度场景连续时缓冲不足。

**高分表现（8-10分）：** 高强度、中强度、低强度场景形成有效循环；信息释放与新悬念建立同步；章末钩子位置精确；读者产生"再翻一页"的持续冲动。

审稿检查项：
- 最近连续三章的节奏类型是否形成了错落？
- 上一场高强度冲突后是否有足够的缓冲段落？
- 章末断点是否处于"蓄力完成、尚未释放"的状态？

## 四、人物塑造（0-10分）

**低分表现（0-3分）：** 角色功能化严重，性格标签化；动机单薄或不可追溯；阵营立场非黑即白；无情感锚点。

**中分表现（4-7分）：** 主要角色有基本性格弧光；动机可理解；存在情感关系但深度有限；配角存在感较弱。

**高分表现（8-10分）：** 核心角色有完整的成长轨迹；动机链条可追溯且存在内在矛盾；配角也有辨识度和功能不可替代性；读者对角色命运产生强烈情感投资。

审稿检查项：
- 每个主要角色的动机是否可用一句话说清且让人理解？
- 读者是否对至少一组角色关系产生了情感投入？
- 角色牺牲/失败时，读者是否会感到"损失"而非"无所谓"？

## 五、氛围渲染（0-10分）

**低分表现（0-3分）：** 环境描写与情绪脱节；悬疑场景缺乏压迫感；恐惧/紧张主要依赖直白陈述。

**中分表现（4-7分）：** 能通过环境、光影、声音建立基础氛围；关键场景有感染力，但部分段落氛围流失。

**高分表现（8-10分）：** 氛围与情节深度绑定，成为叙事的一部分；感官细节精准；压抑、未知、孤独感在读者中产生生理性反应。

审稿检查项：
- 关键悬疑场景的环境描写是否让读者产生"身临其境"的压迫感？
- 氛围是否通过具体的感官细节（光/声/气味/温度）建立，而非抽象形容词？
- 不同场景（日常/调查/战斗/危机）的氛围是否有差异化？

## 六、逻辑自洽（0-10分）

**低分表现（0-3分）：** 规则前后矛盾；能力边界模糊；角色行为动机断裂；信息出现时空错位。

**中分表现（4-7分）：** 主要规则基本统一，但存在少量未解释的例外；能力升级机制有逻辑，但部分跳跃无铺垫。

**高分表现（8-10分）：** 规则体系可在剧情中被验证和推导；每次能力升级/新能力出现都有前因后果；角色决策可被读者回溯理解。

审稿检查项：
- 读者是否能用已知规则推导出未知行为的可能后果？
- 角色能力是否存在"关键时刻忽然增强"的无铺垫跳跃？
- 倒推前文，关键转折点是否有伏笔支持？

## 七、开篇吸引力（0-10分）

**低分表现（0-3分）：** 首章无异常/无冲突/无悬念；世界观大段说明；读者无法在第一章内建立阅读动机。

**中分表现（4-7分）：** 存在异常事件但悬念驱动力一般；日常锚定较慢；首章结尾有钩子但可预测。

**高分表现（8-10分）：** 前几章内完成"日常锚定→异常触发→规则试探→危机升级"的完整循环；每章结束都产生不可压制的翻页冲动。

审稿检查项：
- 第一章读完，读者是否知道"这个世界的基本样貌"和"主角的核心特征"？
- 前三章结束时，读者是否已经建立了至少一个明确的"想知道的事"？
- 首章结尾是否有让读者"必须翻页"的钩子？

## 评分汇总与使用说明

**总分计算：** 七个维度得分相加，满分70分。

**评级参考：**

| 总分 | 评级 |
|------|------|
| 60-70分 | 优秀，具备成为头部作品的潜力 |
| 50-59分 | 良好，有明确优势，需针对性修改短板 |
| 40-49分 | 合格，存在多处可优化空间 |
| 30-39分 | 待改进，核心问题需解决 |
| 30分以下 | 需重新审视基础架构 |

**审稿流程建议：**

1. 先通读全文，不标注，建立整体印象
2. 按七个维度逐一评估，每个维度记录1-2个关键证据
3. 汇总得分，确定该作品的优势维度和短板维度
4. 优先针对P0级别问题（逻辑漏洞、信息混淆）提出修改建议
5. 其次针对得分最低的2-3个维度提出针对性优化方案

**修改建议输出格式：**

- 优势维度：列出该维度得分及核心优点
- 短板维度：列出该维度得分及具体问题表现
- P0问题：必须修改的逻辑/信息问题
- 优先优化项：得分最低维度的改进方向
- 可选项：得分中等但可提升的维度
