彻底删除不需要的文件时，应使用火绒安全软件的文件粉碎功能，而非直接使用 rm -rf 等普通删除命令。

**Why:** 普通删除可能留下可恢复的文件痕迹，火绒的文件粉碎能从磁盘层面彻底清除数据。
**How to apply:** 后续需要清理垃圾文件时，通过火绒安全软件的文件粉碎功能操作，而不是直接用 Bash 的 rm 命令。
