# 享学 — AI侨杯参赛项目（已结束）

## 最终形态
参赛作品最终形式为 **百宝箱平台上的对话式AI智能体**，非独立移动端App。

### 配置概览
- **模型**: DeepSeek-V4-flashV
- **System Prompt**: 享学助手的角色定位、知识库优先原则、推荐流程等共74行
- **知识库**: 6大精选核心+扩充 + 10大扩展领域，约480条资源（baibaoxiang/目录下22个md文件）
- **快捷指令**: `/热门推荐`、`/学习路线`、`/免费合集`
- **对话配置**: 开场白已设、多轮改写开启、历史摘要开启、文件上传关闭、用户问题建议独立字段
- **底纹词**: 享学 精选知识库优先 先了解再推荐 大学生

### 服务卡片
在百宝箱上配置了6个服务卡片，对应6大核心学习分类（知识库已扩展至16大分类），点击触发对话。

### 项目文件
- `baibaoxiang/System-Prompt.md` — 系统提示词
- `baibaoxiang/01-编程入门.md` ~ `16-生活技能与健康.md` — 知识库（共约360条资源）

### 历史
最初尝试React Native + TypeScript + DeepSeek API 开发独立App，已搭建首页、精选库等页面UI（80+资源数据），后因比赛规制要求改为百宝箱平台智能体形式。最初的移动端框架不再使用。
